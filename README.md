# SIH Insight – Smart India Hackathon Management System

## About the Project
SIH Insight is a MySQL-based DBMS mini project designed to organize and manage Smart India Hackathon (SIH) problem statements, editions, organizations, themes, student teams, projects, and submissions.

## Features
- Management of SIH problem statements.
- Organization and theme categorization.
- Student and team management.
- Project and submission tracking.
- SQL queries for data analysis.
- Views for reports.
- Stored procedures and functions.
- Triggers and student audit logging.

## Technologies Used
- MySQL
- MySQL Workbench
- SQL
- Python

## Database Overview
The database includes tables for:
- Students and Teams
- Problem Statements
- Organizations and Themes
- Projects and Technologies
- Submissions and Reviews
- Results and Documents

## Project Files
| File | Description |
|---|---|
| `01_schema.sql` | Database schema |
| `02_original_sih_data.sql` | SIH problem statement dataset |
| `03_sample_project_data.sql` | Demonstration records |
| `04_queries.sql` | SQL query exercises |
| `05_views_reports.sql` | Database views |
| `generate_original_data.py` | Dataset generation script |
| `GENERATE_ORIGINAL_SQL.bat` | Windows execution script |
| `README_FIRST.txt` | Setup instructions |

## How to Run
1. Open MySQL Workbench.
2. Execute `01_schema.sql`.
3. Execute `02_original_sih_data.sql`.
4. Execute `03_sample_project_data.sql`.
5. Execute `04_queries.sql`.
6. Execute `05_views_reports.sql`.

## Data Source
The problem statement data is based on community-maintained SIH dataset exports. It is not represented as a direct official portal download.

## Project Purpose
This project demonstrates relational database design, SQL queries, data management, reporting, stored procedures, functions, and triggers.
